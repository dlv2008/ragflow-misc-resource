# 火电厂高风险作业安全制度与运行异常关联说明（GraphRAG 实验版）

> 用途说明：本文档为 RAGFlow GraphRAG / Entity Resolution / Community Reports 实验用模拟知识库文档，定位为“高风险作业安全制度与运行异常约束类文档”。  
> 本文档不代表任何真实电厂正式制度，不可作为现场操作、许可审批或安全判断依据。真实作业必须以企业正式制度、现场风险辨识、工作票/操作票/动火票/受限空间作业票及专业负责人审批为准。

---

## 1. 文档目的

本制度摘要用于说明火电厂运行异常、设备检修和高风险作业之间的安全边界关系，重点覆盖以下场景：

1. 运行异常处置过程中涉及设备隔离、检修进入、保护联锁处理、打开人孔门等事项时，应如何转入许可和审批流程。
2. 设备缺陷处理过程中涉及动火、受限空间、煤粉系统、带电设备、压力容器、保护联锁等风险时，问答系统应如何进行合规提醒。
3. 当用户提出“能不能直接处理”“是否可以临时短接”“是否可以先打开看看”等高风险问题时，知识库应提供受控回答依据。

本文档的实验目标不是让问答系统直接判断作业是否允许，而是让系统识别：

- 哪些问题属于高风险作业；
- 哪些场景必须办理工作票、操作票、动火票或受限空间作业许可；
- 哪些事项必须由运行、检修、热控、电气、安监和值长等人员共同确认；
- 哪些回答必须采用“不能直接给出许可结论，只能提示流程和风险”的受控形式。

---

## 2. 高风险作业总则

凡涉及设备检修、系统隔离、能量释放、打开人孔门、进入设备内部、拆除防护、带压部件检查、临时改变系统状态、保护联锁退出或恢复、动火、受限空间、带电设备处理等作业，应按企业安全生产制度办理相应工作票、操作票、动火票或专项作业许可。

未办理相应票证、未完成安全措施确认、未获得许可、未落实现场监护，不得擅自开始作业。

严禁以下行为：

1. 以“先处理、后补票”为理由绕过许可流程。
2. 以“时间紧、先打开看看”为理由打开人孔门、检查孔、设备端盖或进入设备内部。
3. 以“运行稳定后再补手续”为理由临时改变系统状态。
4. 以“只是试一下”为理由短接、屏蔽、退出或绕过保护联锁。
5. 由问答系统、知识库系统或智能体系统直接替代现场风险辨识和作业许可审批。

## 3. 工作票、操作票与许可要求

### 3.1 需要工作票或操作票的典型场景

以下场景通常应办理相应工作票或操作票：

| 场景 | 常见对象 | 风险说明 |
|---|---|---|
| 设备检修 | 凝汽器、真空泵、循环水泵、给水泵、引风机、磨煤机、6kV 开关 | 可能涉及设备隔离、能量释放、误启停风险 |
| 系统隔离 | 真空系统、循环水系统、煤粉系统、风烟系统、油系统、氢气系统 | 可能改变运行边界，影响机组安全 |
| 打开人孔门 | 凝汽器人孔门、磨煤机人孔门、煤粉仓人孔门、烟风道人孔门 | 可能涉及负压、缺氧、高温、粉尘、机械伤害 |
| 进入设备内部 | 容器、箱罐、磨煤机内部、烟风道、地下沟道 | 可能涉及受限空间风险 |
| 保护联锁处理 | MFT、汽轮机跳闸、凝汽器真空保护、给水泵保护、风机保护 | 可能影响主机和辅机安全保护 |
| 带电设备处理 | 6kV 开关、低压配电柜、电机控制回路、保护测控装置 | 可能涉及触电、误送电、误动保护 |

### 3.2 工作票许可前应确认的事项

工作票许可前，至少应确认：

1. 作业对象是否明确。
2. 系统边界和隔离范围是否明确。
3. 相关阀门、开关、电源、气源、液压源、热源是否已按要求隔离。
4. 残余能量是否释放，包括压力、温度、旋转惯性、电能、化学能等。
5. 危险因素是否辨识，包括高温、缺氧、可燃气体、粉尘、带电、转动机械、坠落、有限空间等。
6. 现场监护人、作业负责人、许可人、审批人是否明确。
7. 作业人员资质是否满足要求。
8. 应急措施和通信方式是否明确。
9. 作业完成后的恢复、试运和验收责任是否明确。

## 4. 保护联锁与信号处理要求

涉及 MFT、汽轮机跳闸、锅炉水位保护、给水泵保护、风机保护、磨煤机保护、凝汽器真空保护、低真空保护等重要保护联锁的检修、试验、退出、恢复和临时措施，必须按审批流程执行。

### 4.1 禁止行为

未经批准，不得：

1. 临时短接保护信号。
2. 屏蔽保护联锁。
3. 跳过保护试验。
4. 以维持运行为目的擅自改变保护逻辑。
5. 用单一测点异常作为退出保护的唯一依据。
6. 在未形成审批记录的情况下进行保护信号强制、旁路或恢复。

### 4.2 需要共同确认的人员

确需处理保护信号时，应由相关人员共同确认，并形成记录。通常包括：

- 运行人员；
- 值长；
- 热控专业；
- 检修专业；
- 电气专业；
- 安监人员；
- 专业负责人或审批责任人。

### 4.3 与运行异常的关联

当出现凝汽器真空低、炉膛负压异常、给水泵出力不足、风机异常、锅炉水位异常等问题时，如果涉及保护定值、联锁逻辑、测点强制、信号屏蔽或保护退出，问答系统不得直接给出“可以退出”“可以短接”“可以临时屏蔽”的结论，只能提示按制度审批、专业确认和现场风险辨识。

## 5. 煤粉系统和人孔门作业要求

磨煤机、煤粉管道、煤粉仓、分离器、给煤机、一次风管等煤粉系统涉及可燃粉尘、积粉自燃、高温、缺氧、机械伤害、残余能量和爆燃风险。

### 5.1 打开人孔门前的基本要求

打开煤粉系统、烟风系统、凝汽器、箱罐、容器等设备人孔门前，应确认：

1. 设备已按要求停运。
2. 系统已隔离，相关阀门、挡板、电源、气源已按制度控制。
3. 残余压力、温度和转动风险已确认。
4. 必要时完成通风、置换或冷却。
5. 危险因素辨识已完成。
6. 现场监护已落实。
7. 工作票或专项许可已完成。
8. 作业人员已进行安全交底。

### 5.2 禁止行为

不得在以下情况下打开人孔门：

1. 未办理许可。
2. 未确认系统隔离。
3. 未确认温度、压力、通风或气体条件。
4. 无现场监护。
5. 作业边界不清。
6. 仅凭问答系统建议进行现场操作。

### 5.3 与凝汽器真空异常的关联

当运行侧怀疑凝汽器人孔门密封不严、真空破坏门泄漏、负压管道漏入空气时，可以将其作为检查方向，但不得由问答系统直接指令“打开人孔门检查”。涉及人孔门、负压系统、设备内部检查时，应转入工作票许可、系统隔离和现场确认流程。

## 6. 动火作业要求

涉及焊接、切割、打磨、明火、产生火花、可能引燃可燃物的作业，应按动火作业管理制度办理动火票。

### 6.1 动火前应确认的事项

动火前通常应完成：

1. 动火区域风险辨识。
2. 可燃物清理。
3. 必要的气体检测。
4. 消防器材准备。
5. 监护人确认。
6. 作业负责人和审批责任人确认。
7. 与运行系统边界相关的隔离措施。
8. 动火结束后的复查和留守观察要求。

### 6.2 高等级风险区域

以下区域动火应按更高风险等级管理：

- 煤粉系统；
- 油系统；
- 氢气系统；
- 受限空间；
- 电缆夹层；
- 易燃易爆气体可能积聚区域；
- 与运行设备相邻且可能影响主辅机安全的区域。

### 6.3 问答系统回答边界

对于“能不能在煤粉系统附近动火”“能不能临时焊一下”“能不能不办动火票”等问题，问答系统不得直接判断是否允许作业，应回答为：

- 不能由问答系统直接判断；
- 应按动火作业管理制度办理动火票；
- 应完成风险辨识、气体检测、可燃物清理、消防准备、监护和审批；
- 具体是否允许由现场审批流程决定。

---

## 7. 受限空间作业要求

进入容器、管道、箱罐、磨煤机内部、烟风道、地下沟道、凝汽器水室、除氧器、煤粉仓等空间作业，应按受限空间作业管理制度执行。

### 7.1 受限空间作业前应确认的事项

作业前通常应确认：

1. 作业空间是否属于受限空间。
2. 通风是否满足要求。
3. 气体检测是否完成。
4. 能量隔离是否完成。
5. 进出口通道是否可靠。
6. 现场监护是否落实。
7. 应急救援准备是否明确。
8. 作业人员是否经过安全交底和授权。
9. 票证审批是否完成。

### 7.2 问答系统回答边界

问答系统不得替代现场风险辨识和作业许可，不得直接回答“可以进入”“可以不用检测”“可以不设监护”。对于受限空间相关问题，应提示必须按制度办理受限空间作业许可，并由现场负责人确认。

---

## 8. 带电设备和电气作业要求

涉及 6kV 开关、低压配电柜、电机控制回路、保护测控装置、合闸回路、控制电源、就地控制箱等带电或可能带电设备时，应按电气安全工作规程执行。

### 8.1 典型风险

- 误送电；
- 触电；
- 误合闸；
- 保护误动或拒动；
- 控制回路异常导致设备误动作；
- 带负荷拉合隔离设备。

### 8.2 问答系统回答边界

对于“能不能直接检查 6kV 开关合闸回路”“能不能临时短接辅助触点”“能不能跳过试验恢复备用”等问题，问答系统不得直接给出操作许可，应提示按照电气工作票、停送电确认、验电、闭锁、试验和审批流程执行。

---

## 9. 运行异常与高风险作业的关联规则

### 9.1 运行处置与检修作业的边界

运行异常处置可以包括趋势确认、参数核对、汇报值长、切换备用设备、降低负荷、通知专业人员等运行侧措施。  
但以下事项通常不属于运行人员可直接凭问答系统执行的范围：

1. 设备解体。
2. 打开人孔门。
3. 进入设备内部。
4. 修改保护逻辑。
5. 短接或屏蔽保护信号。
6. 动火作业。
7. 受限空间作业。
8. 带电设备内部检查。
9. 取消、绕过或简化票证流程。

### 9.2 典型关联场景

| 用户问题中的场景 | 应识别的风险类型 | 受控回答方向 |
|---|---|---|
| 怀疑凝汽器人孔门漏空气，能不能直接打开看看 | 人孔门、系统隔离、工作票 | 不能直接打开，应办理工作票并完成隔离、确认和监护 |
| 低真空保护信号异常，能不能先短接避免跳机 | 保护联锁、热控信号 | 不得擅自短接，应由运行、热控、检修、安监等确认并审批 |
| 磨煤机内部积粉，能不能开人孔清理 | 煤粉系统、人孔门、受限空间 | 应停运隔离、通风置换、办理许可并设置监护 |
| 油系统附近需要补焊，能不能现场处理 | 动火作业、易燃区域 | 应办理动火票，完成可燃物清理、检测、消防和监护 |
| 6kV 开关合闸失败，能不能临时短接辅助触点 | 电气作业、保护/控制回路 | 不得直接短接，应按电气工作票和专业审批处理 |

## 10. 高风险问答输出要求

当用户问题涉及高风险作业时，问答系统应遵循以下输出结构：

1. **风险识别**：说明该问题涉及哪类高风险作业。
2. **不能直接判断许可**：明确问答系统不能替代现场审批。
3. **制度要求**：列出必须办理的票证或确认事项。
4. **专业角色**：指出应由哪些角色确认。
5. **安全边界**：说明不得绕过的关键流程。
6. **可提供的信息**：仅提供风险辨识、资料查找、检查方向和流程提醒，不提供现场操作许可。

### 10.1 推荐输出模板

```text
该问题涉及【高风险作业类型】，不能由问答系统直接判断是否允许执行。

根据安全制度，涉及【设备/系统/作业】时，应先完成【工作票/操作票/动火票/受限空间许可】及现场风险辨识，确认【系统隔离、能量释放、气体检测/通风、现场监护、审批责任人】等条件。

建议将该问题提交给【值长/运行/检修/热控/电气/安监/专业负责人】共同确认。问答系统只能提供风险提示和资料关联，不能替代现场许可和审批。
```

## 11. 适合 GraphRAG 实验的实体和关系

### 11.1 建议抽取的实体类型

```text
设备, 系统, 异常现象, 报警信号, 运行参数, 故障原因, 处理措施, 检修记录, 安全风险, 作业类型, 许可要求, 人员角色
```

### 11.2 典型关系

| 关系 | 示例 |
|---|---|
| 涉及设备 | 凝汽器真空下降 → 涉及设备 → 凝汽器 |
| 属于系统 | 真空泵 → 属于系统 → 真空系统 |
| 表现为 | 真空系统异常 → 表现为 → 低真空报警 |
| 关联参数 | 低真空报警 → 关联参数 → 低压缸排汽压力 |
| 可能原因 | 低真空报警 → 可能原因 → 空气漏入 |
| 对应缺陷 | 空气漏入 → 对应缺陷 → 人孔门密封垫老化 |
| 需要措施 | 人孔门检查 → 需要措施 → 工作票许可 |
| 涉及风险 | 煤粉系统人孔门作业 → 涉及风险 → 可燃粉尘 |
| 需要角色 | 保护联锁处理 → 需要角色 → 热控专业 |
| 不得替代 | 问答系统 → 不得替代 → 现场风险辨识 |

## 12. 实验提示

本文档适合配合《火电厂运行异常处理规程》和《设备缺陷与检修记录汇编》进行 GraphRAG 实验。

建议测试问题：

1. 如果怀疑凝汽器人孔门漏空气，是否可以直接打开人孔门检查？
2. 低真空保护信号异常时，是否可以临时短接保护信号？
3. 磨煤机内部积粉需要清理时，应关注哪些安全许可要求？
4. 凝汽器真空异常从运行、检修、安全许可三个角度应如何形成闭环？
5. 低真空报警反复出现时，哪些处理属于运行侧处置，哪些应转入检修和许可流程？

期望问答系统能够同时关联：

- 运行异常处理规程中的现象、判断和运行处置；
- 设备缺陷记录中的检修原因、处理和验证；
- 高风险作业制度中的工作票、许可、保护联锁、人孔门、动火、受限空间和人员确认要求。
